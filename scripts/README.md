# 東京都・1法人1居宅介護支援事業所 抽出

## 実行

```bash
pip install pandas openpyxl
python3 scripts/extract_tokyo_1houjin_1kyotaku.py [CSVパス]
```

CSVパスを省略した場合は厚労省サイトからダウンロードを試みます。

データ元: 厚生労働省 介護サービス情報公表システム オープンデータ
(居宅介護支援・全国版) `jigyosho_430_all_*.csv`

## 処理内容

1. CSVを cp932 → utf-8-sig の順に試して読み込み（見出し行も自動検出）
2. 列名は年度ごとに揺れるため、正規表現による部分一致で自動解決
   （`_かな` 列や `事業の開始年月日` などは除外）。解決結果は実行時に表示され、
   見つからなかった列は空欄で出力したうえで警告を出す
3. 東京都で絞り込み。都道府県列があればそれを、無ければ事業所所在地の先頭一致
4. エリア（区市町村）を付与。市区町村列があればそれを使い、無ければ住所から
   切り出す（`武蔵村山市` を `武蔵村` で切らない／`西多摩郡奥多摩町` は
   `奥多摩町` に正規化）
5. 法人名・法人所在地をNFKC正規化＋全角英数の半角化＋空白除去したものをキーに
   グルーピングし、件数が1件の法人のみ抽出
6. `tokyo_1houjin_1kyotaku.xlsx` を出力
7. 総事業所数と1法人1事業所の件数を標準出力に表示

## 出力Excelの構成

| シート | 内容 |
| --- | --- |
| 対象リスト | 抽出結果の全件（架電記入欄つき） |
| エリア別集計 | 区市町村ごとの対象件数と東京都全件数 |
| 各区市町村名 | 対象リストをエリアで分割したもの（架電記入欄つき） |
| 全東京都 | 東京都の全件（参照用） |

### 列構成

基本情報（濃紺の見出し）:
`No` / `エリア` / `法人名` / `代表者名` / `管理者名` / `法人所在地` /
`事業所名` / `事業所番号` / `事業所所在地` / `電話番号` / `FAX` /
`ホームページ` / `指定年月日`

架電記入欄（橙の見出し・空欄で出力）:
`架電状況` / `架電日` / `架電回数` / `担当者` / `対応者(役職・氏名)` /
`見込み度` / `通話メモ` / `次回アクション` / `次回架電予定日` / `備考`

`架電状況` と `見込み度` はプルダウン（入力規則）付き。

### 書式

全シート共通で、1行目固定・オートフィルタ・列幅の自動調整（日本語を2幅として計算）
を適用しています。
