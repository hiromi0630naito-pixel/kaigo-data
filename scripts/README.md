# 東京都・1法人1居宅介護支援事業所 抽出

## 実行

```bash
pip install pandas openpyxl
python3 scripts/extract_tokyo_1houjin_1kyotaku.py [CSVパス]
```

CSVパスを省略した場合は厚労省サイトからダウンロードを試みます。

データ元: 厚生労働省 介護サービス情報公表システム オープンデータ
(居宅介護支援・全国版) `jigyosho_430_all_*.csv`

## 処理内容

1. CSVを cp932 → utf-8-sig の順に試して読み込み（見出し行も自動検出）
2. 列名は年度ごとに揺れるため、正規表現による部分一致で自動解決
   （`_かな` 列や `事業の開始年月日` などは除外）。解決結果は実行時に表示され、
   見つからなかった列は空欄で出力したうえで警告を出す
3. 東京都で絞り込み。都道府県列があればそれを、無ければ事業所所在地の先頭一致
4. エリア（区市町村）を付与。市区町村列があればそれを使い、無ければ住所から
   切り出す（`武蔵村山市` を `武蔵村` で切らない／`西多摩郡奥多摩町` は
   `奥多摩町` に正規化）
5. 同一法人の名寄せ。**法人番号**があればそれをキーにする（最も正確）。
   法人番号が空欄の行だけ、法人名・法人所在地をNFKC正規化＋全角英数の半角化
   ＋空白除去したキーで補完する。件数が1件の法人のみ抽出
6. `tokyo_1houjin_1kyotaku.xlsx` を出力
7. 総事業所数と1法人1事業所の件数を標準出力に表示

| シート | 内容 |

| 除外リスト | 除外した行と、その理由 |
| 1法人1事業所(都内) | 都内に1事業所のみの法人（架電記入欄つき） |
| 1法人1事業所(全国) | さらに全国でも1事業所のみに絞ったもの |
| 架電リスト(全件) | 東京都の全事業所（架電記入欄つき） |
| エリア別集計 | 区市町村ごとの各件数 |
| 電話番号_要確認 | 架電前に目視すべき行（表記ゆれ・桁数異常・番号重複） |
| 各区市町村名 | 全件をエリアで分割したもの（架電記入欄つき） |

`都内1事業所` `全国1事業所` 列（`○` / 空）と `都内事業所数` `全国事業所数`
列で絞り込めるため、
エリア別シートは全件を収録しています。`No` は全シートで同じ行を指します。

### 列構成

基本情報（濃紺の見出し）:
`No` / `エリア` / `都内1事業所` / `全国1事業所` / `都内事業所数` /
`全国事業所数` / `事業所タイプ(推定)` / `法人番号` / `法人名` / `代表者名` / `管理者名` /
`法人所在地` / `事業所名` / `事業所番号` / `事業所所在地` / `電話番号` /
`FAX` / `ホームページ` / `利用可能曜日` / `指定年月日`

`電話番号` は元データの原文をそのまま保持し、`電話番号(整形)` に半角数字と
ハイフンだけへ整えたものを併記します。整形処理は数字を一切変更せず、
全件で「原文の数字 == 整形後の数字」を検証し、1件でも不一致があれば
実行を中断します。

元データに存在しない列は自動的に落とします。ただし `代表者名` `管理者名`
`指定年月日` は架電時に手で埋められるよう、空欄のまま残します。

架電記入欄（橙の見出し・空欄で出力）:
`記録者` / `架電状況` / `架電日` / `架電回数` / `対応者` / `見込み度` /
`次回アクション` / `次回架電予定日` / `希望時間帯` / `通話メモ` / `備考`

`通話メモ` `備考` 以外はすべてプルダウン（入力規則）付き。`架電日`
`次回架電予定日` は日付の入力規則をかけています。選択肢は
スクリプト冒頭の `CHOICES` で変更できます。

### 書式

全シート共通で、1行目固定・オートフィルタ・列幅の自動調整（日本語を2幅として計算）
を適用しています。

## 元データについて（2026-07-09版で確認）

配布CSVは24列で、エンコーディングは **utf-8-sig** でした（cp932ではない）。
スクリプトは両方に対応しています。主な対応関係:

| 出力列 | 元CSV列 |
| --- | --- |
| 法人名 | 法人の名称 |
| 法人番号 | 法人番号 |
| エリア | 市区町村名 |
| 事業所所在地 | 住所（+ 方書（ビル名等）） |
| ホームページ | URL |
| FAX | FAX番号 |

`方書（ビル名等）` の値は全件が `住所` 側に既に含まれていたため、
連結時に重複分を読み飛ばしています。

**元データに存在しない項目**: `代表者名` `管理者名` `指定年月日` `法人所在地`。
このオープンデータには含まれないため、取得できません。

## 電話番号の扱い

架電リストという用途上、電話番号の正確さを最優先にしています。

- **原文を改変しない**: `電話番号` 列は元CSVの値をそのまま入れます
- **整形は別列**: `電話番号(整形)` に半角数字＋ハイフンだけの表記を併記
- **数字の不変を全件検証**: 整形の前後で数字列が一致することを確認し、
  不一致があれば `RuntimeError` で停止します
- **文字列として保存**: 先頭ゼロが落ちないよう、電話番号・FAX・事業所番号・
  法人番号はすべて文字列セルとして書き出します
- **区切りのない番号にハイフンを補う**: 表計算ソフトが数値と解釈して先頭の0を
  落とすのを防ぐため、桁の切り方が一意に決まる場合だけハイフンを入れます
  （11桁の050/070/080/090は3-4-4、10桁の03始まりは2-4-4）。市外局番の
  桁数が一意に決まらない042系などは変更しません
- **要確認シート**: 表記ゆれ、桁数異常、他法人との番号重複を洗い出します

2026-07-09版データ（東京都2,893件）での検証結果:

- 電話番号の欠損: 0件
- 元CSVとの不一致: 0件
- 表記ゆれ: 178件（全角数字・全角ハイフン・丸括弧・読点など）
- 他法人と同一番号: 6件
- 桁数異常: 1件（大田区 けいひん訪問看護ステーション、原文
  `直通03-5744-488` が9桁。元データ側の誤りと思われる）
- 11桁の行はすべて携帯・IP電話（050/070/080/090）で正常

## 1法人1事業所の判定について

### サービス種別

元CSVは全36,212行が `サービスの種類 = 居宅介護支援` の単一種別です。
したがって収録されている事業所はすべて居宅介護支援の指定事業所であり、
事業所数のカウントも居宅介護支援事業所の数を数えています。

### 都内基準と全国基準

`都内事業所数` は東京都内だけを数えたものです。東京都で1事業所でも、
他県に多数の拠点を持つ法人が含まれます（2026-07-09版で105件）。
そのため `全国事業所数` を別途付与し、`全国1事業所` で絞り込めるように
しています。全国数は法人番号ベースで全国36,212行から算出します。

### 事業所タイプ(推定)

全件が居宅介護支援の指定事業所ですが、母体が病院や特養で、その一部門として
居宅介護支援を持つ事業所も含まれます。`事業所タイプ(推定)` は事業所名から
母体施設を推定した列で、`独立系` / `医療機関併設` / `訪問看護併設` /
`施設併設` / `薬局併設` / `社協・包括` に分類します。

**この列は事業所名の文字列からの推定であり、確定情報ではありません。**
名称に母体施設名が出ていない併設事業所は `独立系` に分類されます。

### 法人番号が空欄の行

全国36,212行のうち975行は法人番号が空欄です（東京都内は0件のため、
都内の名寄せには影響しません）。ただし全国数の算出からは除外されるため、
都内1事業所の法人と同名の空欄行が8件あり、これらは全国数を実際より
少なく数えている可能性があります。

## 法人種別の判定

`法人種別` 列は法人名の文字列から法人格を判定したものです。
`公的機関` / `社協` / `社会福祉法人` / `医療法人` / `公益法人` /
`学校・宗教` / `協同組合` / `NPO` / `一般社団・財団` / `営利法人` /
`不明(法人格の記載なし)` に分類します。

「民間」として架電対象にするのは `営利法人`（株式会社・有限会社・
合同会社・合資会社・合名会社）のみで、`MINKAN_TYPES` で変更できます。

法人名に法人格が書かれていない行（`e笑顔`、`ゆとりケア` など）は判定
できないため `不明(法人格の記載なし)` とし、民間リストからは外して
別シート・別CSVに出しています。件数が少ないので目視で振り分けられます。

## 架電リストからの除外条件

`exclusion_reasons()` が各行の除外理由を組み立て、理由が空の行だけが
最終リストに残ります。除外した行は理由つきで `除外リスト` に出ます。

| 条件 | 理由 |
| --- | --- |
| 民間(営利法人)でない | 医療法人・社会福祉法人・NPO等は決裁構造が異なる |
| 併設事業所 | 母体（病院・特養・訪看・薬局）側の決裁になりやすい |
| 他県にも拠点あり | 本社決裁の可能性が高く、小規模事業者ではない |
| 島嶼部 | 訪問できず架電効率も悪い |
| 電話番号が他社と重複 | 同じ番号への二重架電を防ぐ（2件目以降を落とす） |

条件を変えたい場合は `exclusion_reasons()` の該当行を消すか、
`ISLANDS` / `MINKAN_TYPES` を書き換えてください。除外した行は
`除外リスト` シートに残っているので、後から戻すこともできます。

`電話種別` 列（固定(23区) / 固定(多摩等) / 携帯 / IP電話）は、
架電の当たり方や優先順位づけに使えます。

## Googleスプレッドシートで使う場合

CSVをそのまま読み込ませると、区切りのない番号が数値と解釈されて先頭の0が
消えます（`0424976051` → `424976051`）。FAXや法人番号も同様です。

**xlsxをGoogleドライブにアップロードして開くのが確実です。** xlsxはセルごとに
型を持つため文字列がそのまま保持され、プルダウン（入力規則）も引き継がれます。

CSVを使う場合は、スプレッドシートの「ファイル > インポート」から読み込み、
**「テキストを数値、日付、数式に変換する」のチェックを外して**ください。
ドライブへのドラッグ&ドロップではこの選択肢が出ないため、先頭の0が落ちます。
